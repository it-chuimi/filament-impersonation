# Filament Impersonation

Controlled user impersonation plugin for Laravel and Filament applications.

> This package is under initial development.

## Requirements

- PHP 8.2 or higher
- Laravel 12 or higher
- Filament 5 or higher
- spatie/laravel-activitylog

## Installation

```bash
composer require chuimi/filament-impersonation
```
